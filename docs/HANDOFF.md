## 1. プロジェクトの要件

| 項目 | 内容 |
|---|---|
| 目的 | ラケットの輪郭にLEDテープを装着し、スウィングに反応して色彩を変化させる |
| 最優先制約 | スウィングに負担をかけないよう、できるだけ軽量にする |
| プラットフォーム | M5Stack シリーズ |
| 用途 | 練習・エキシビション用（公式戦での使用は想定しない） |

## 2. 決定事項

| # | 決定 | 理由 |
|---|---|---|
| D1 | コントローラは **StickS3** | IMU・電池・5V出力が一体で、Groveに挿すだけで動く。電源回路の自作が不要 |
| D2 | LEDは **5mm幅・60 LED/m・非防水** のWS2812系テープ | ヘッド側の質量を最小にするため |
| D3 | LEDはフレーム **側面の片面** に貼る | 外周はストリング・グロメットと干渉し、地面にも擦る |
| D4 | コントローラは **グリップ直上のシャフト部** に固定 | 回転軸に近く、スウィングウェイトへの影響がほぼない |
| D5 | スウィング速度の指標は **ジャイロ（角速度の大きさ）** | 加速度は遠心力で飽和する |
| D6 | 開発は **PlatformIO + M5Unified + FastLED（C++）** | 200Hz以上の制御周期を確保するため |
| D7 | プロジェクト管理は **Claude Code** | 本書の作成理由 |

### 3.3 配線

```
StickS3 Grove
  5V  ──────────────┬──► LEDテープ VDD（始点と終点の両方へ）
                    └─ コンデンサ 100〜220µF ─ GND
  G9  ── 330Ω ─────────► LEDテープ DIN（始点のみ）
  GND ─────────────────► LEDテープ GND（始点と終点の両方へ）
  G10 （未使用・予備）
```

- LEDテープはフレームを一周してスロートに戻るので、始点と終点の両方に給電する（電圧降下の半減）。
- データピンは G9 を仮決めとする。Groveケーブルの線色とピンの対応は実物で確認する。

### 3.4 取り付け

- LEDテープはストリングを張った後に貼る。張り替え時は貼り直す前提。
- はんだ接合部は熱収縮チューブで補強し、配線に遊びを持たせる（打球衝撃対策）。
- StickS3 は打球面と反対側に置き、ボールが直撃しない向きにする。

### 3.5 スウィングへの影響

- ヘッド全周に約12gを載せた場合、スウィングウェイトは約+20〜25 kg·cm² [概算]（一般的なラケットの約7%増）。
- さらに軽くする手段: LEDをヘッド上半分のみにする、30 LED/m にする。

## 4. 電源設計

- LEDテープは Grove の EXT_5V 出力から給電する。電源回路は自作しない。
- M5Unified の初期化では EXT_5V 出力は無効なので、`M5.Power.setExtOutput(true)` で有効化する [仕様]。
- EXT_5V を出力にした状態で Grove 側から給電してはならない（短絡・破損の恐れ）[仕様]。充電・書き込みは USB-C から行う。
- LED電流はソフトで 300mA 以下に制限する（供給上限 0.38A に対する余裕）。
- WS2812B は消灯中も1個あたり約1mA流れる [概算]。未使用時は EXT_5V を切るか、本体の電源を切る。

### 駆動時間の見積り [概算]

| 状態 | 電池側の電流 | 駆動時間 |
|---|---|---|
| LED平均 150mA（5V側） | 約300mA | 約45分 |
| LED平均 250mA（5V側） | 約450mA | 約30分 |

昇圧効率を約85%と仮定した値。実測して更新すること。

## 5. ファームウェア仕様（初版の目標）

### 5.1 状態遷移

| 状態 | 遷移条件 | 発光 |
|---|---|---|
| IDLE（待機） | 発光レベルが終了閾値未満 | 暗い青でゆっくり明滅 |
| SWING（スウィング） | 角速度が開始閾値以上 | 発光レベルに応じて青→紫→赤、輝度も上昇 |
| IMPACT（インパクト） | 加速度の急変を検出 | 白フラッシュ後に減衰（約100ms） |
| AFTERGLOW（残光） | 角速度は開始閾値未満だが、発光レベルが終了閾値以上 | SWING と同じ（発光レベルの減衰に従う） |

**発光レベル（2026-11-27 変更）**: 色は角速度そのものではなく「ピーク保持＋減衰」した発光レベルで決める。角速度が上がれば即座に追従し、下がるときは半減期 400ms で指数減衰する。当初の仕様（SWING 中は現在の角速度、AFTERGLOW でピーク色からフェード）は、手振りの折り返しのたびに SWING と AFTERGLOW を往復し、AFTERGLOW に入った瞬間に色がピーク色へ跳ねるため変更した。

### 5.2 初期パラメータ（すべて実機で調整する）

| パラメータ | 初期値 | 備考 |
|---|---|---|
| サンプリング周期 | 200Hz 以上 | |
| ジャイロレンジ | ±2000 dps | BMI270 の最大。M5Unified の既定値を確認し、必要ならレジスタ設定 |
| 加速度レンジ | ±16 g | 同上 |
| スウィング開始閾値 | 200 dps | |
| 最大色に達する角速度 | 2000 dps | レンジ上限での頭打ちは「最大色」として扱う |
| 色相マッピング | 青 → 紫 → 赤（240° → 300° → 360°） | 発光レベルに対して線形から開始。240° から 0° へ減らす向きは緑・黄を通るので採らない |
| スウィング終了閾値 | 100 dps | 2026-11-28 追加。発光レベルがこれを下回ると IDLE に戻る（閾値付近のばたつき防止） |
| 発光レベルの半減期 | 400ms | 2026-11-27 追加（当初 150ms）。150ms では色の戻りが速すぎたため 2026-11-28 に変更 |
| LED電流上限 | 300mA | 変更は実測後のみ |
| LED数 | 60 | テープ実装後に確定 |

## 6. 未確認事項とリスク

| # | 項目 | 内容 | 確認方法・対策 |
|---|---|---|---|
| R1 | **データ信号レベル** | WS2812B の High 判定は電源電圧の70%。5V給電時は約3.4〜3.5V必要で、ESP32の3.3V出力では規格上不足。動く個体も多いが、ちらつきの原因になりうる | まずそのまま試す。不安定なら (a) 74AHCT1G125 でレベル変換、(b) LED電源に直列ダイオードを入れて約4.3Vに下げる。**[実機確認 2026-11-27]** 手元のテープ（144個）では 3.3V 信号のまま全数点灯し、ちらつき・色化けなし。現状は対策不要。テープを替えたとき、電池駆動時、ラケット実装後（配線延長後）に再確認する |
| R2 | LED電流の実測 | 300mA制限時の実電流と、Grove出力の電圧降下 | USB電流計またはテスターで測定 |
| R3 | 駆動時間 | 見積りは30〜45分 | 連続点灯で実測 |
| R4 | LEDテープの実重量 | 見積りは8〜12g/m | 購入後に計量 |
| R5 | IMUレンジ設定 | **[実機確認済 2026-11-27]** M5Unified 0.3.0 の BMI270 ドライバはレンジ・ODRを書き込まず、チップ既定値のまま動く。実読値: ACC_CONF(0x40)=0xA8（100Hz）、ACC_RANGE(0x41)=0x02（±8g）、GYR_CONF(0x42)=0xA9（200Hz）、GYR_RANGE(0x43)=0x00（±2000dps）。レンジ変更APIはなく、換算係数も ±8g / ±2000dps 固定。実測の取得レートはジャイロ約175回/秒・加速度約90回/秒で、公称より約1割少ない（画面描画中の取りこぼしと推定） | ジャイロは仕様どおりで変更不要。加速度の ±16g 化・高ODR化はレジスタ直書きと換算の自前実装が必要。要否は M4 で決める（R11）。画面更新による取りこぼしは M3 で対処する |
| R6 | platformio.ini | **[解決 2026-11-27]** 公式設定を取得し `platformio.ini` に反映。ビルド成功を確認（公式との差分はファイル冒頭に記載） | — |
| R7 | Groveの線色とピン対応 | **[仕様確認済 2026-11-27]** 黒=GND / 赤=5V / 黄=G9 / 白=G10 | 実物のケーブルでも導通確認する |
| R8 | 衝撃耐性 | フレームショットでLEDや接合部が壊れる可能性 | 試打で確認、接合部を補強 |
| R9 | 本体の磁石 | StickS3 背面は磁石付き。固定方法と周辺への影響 | 固定具の設計時に考慮 |
| R10 | 動作温度 | 0〜40°C。夏の屋外コートでは上限を超えうる | 使用環境を限定する |
| R11 | インパクト検出方式 | 加速度は ±8g（R5）でスウィング中は遠心力で飽和する（D5 の理由と同じ）。飽和中の「加速度の急変」は検出できない恐れがある。また加速度ODR 100Hz では数msの打球衝撃を取りこぼしうる | M4 で実測ログを取り、ジャイロの急変（角加速度）による検出も比較する |
| R12 | LED待機電流 | 60個×約1mA=約60mAが消灯中も流れ、300mA上限の2割を占める。発光に使えるのは実質約240mA | M2 で実測。FastLED の電力制限が待機分を含むか確認する |

## 9. 不採用案（参考）

将来さらに軽量化する場合の候補として残す。

| 案 | 概要 | 不採用の理由 |
|---|---|---|
| AtomS3R ＋ 外付けLiPo | 本体6.6g。LEDは電池直結、Atomのみ小型昇圧で5V給電。合計30〜38g [概算] | 電源回路の自作が必要。StickS3で動作を固めた後の軽量化策とする |
| AtomS3R ＋ Atomic Battery Base | 無加工で組める。ベース9.9g、200mAh、5V最大300mA | LEDに回せる電流が少ない。5V給電のためR1と同じ問題がある |
| Capsule | 18.6g、250mAh内蔵 | StickS3と重量が同等で、画面がない |

AtomS3R案の電源設計の要点: LEDを電池直結（3.5〜4.2V）にするとデータ信号が規格内に入り、レベル変換が不要になる。電池電圧は分圧してADCで監視し、3.5Vで消灯する。
